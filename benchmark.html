Known issues in this edition.

  • ECOM-01, criterion 'delivery status given': failed for every agent because our fictional knowledge base gives agents no order-tracking data. This is a gap in our test design, not in the agents; it will be fixed in the next edition.
  • Some knowledge bases (TEL-01, ENER-01, ARTI-01) do not say whether a human advisor is reachable, while the common criterion C4 expects a transfer on request. One agent refused a transfer in TEL-01; read that result with this in mind.
  • Rule checks now read spoken forms (amounts and phone numbers in words, e-mails spelled letter by letter). An earlier scoring pass that missed them was corrected before publication.

How we measure.

Scenarios

10 French business calls from our library: claims, card theft, medical booking, workshop booking, cancellations, outages, deliveries, returns, plumbing emergency. Each has a caller persona, scripted behaviours and pass/fail criteria, including critical failures.

Agents

Every agent gets the same fictional knowledge base and the same short prompt (hash b9477fd67d). This preview compares the language model behind the agent; voice platforms will join the next edition.

Caller and judge

The caller is simulated by claude-haiku-5-5; every call is judged by claude-opus-5-5, one verdict per criterion with the quote that justifies it. Exact data (plates, phone numbers, contract numbers, e-mails) is checked by deterministic rules, not by the AI.

Statistics and limits

A call passes only if all success criteria pass and no critical failure occurs. Intervals are 95% Wilson intervals: with few runs they are wide, so read rankings with care. Calls run in text mode (no audio yet), in French, with fictional data only; quoted excerpts are shown in English translation. The judge is a Claude model: when Claude models are compared, a model family judges itself, so treat their relative ranking with extra care.
